An original late-night diner cooking game, built for the make.fun
"Make the best cooking game" bounty (`best-cooking-game-20261125-0137`).
See the bounty: https://make.fun/bounty/best-cooking-game-20261125-0137

You are the chef of a small late-night diner. Orders come in on the ticket
rail — burgers, pasta, sushi and more. Grab ingredients from the counters,
chop, fry, boil and plate each dish against the clock, serve it before the
timer runs out, and keep the combo going through the dinner rush.

Play: open `game/index.html` in a desktop browser (keyboard + mouse).
No network requests — pure static files.
